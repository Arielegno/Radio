# Revista nativa (prototipo)

La Revista de Radio de ruta hecha en **Kotlin + Compose Multiplatform**. El mismo código se compila para el navegador (WebAssembly) y, más adelante, para la app de Android.

- Lee de la misma base de datos (Supabase) que la Revista web, con la clave pública y solo lectura.
- Se publica sola en `https://arielegno.github.io/Radio/revista-nativa/` cada vez que cambia esta carpeta.
